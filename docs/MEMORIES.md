# Project Memories and Guidelines

This document tracks important context, guidelines, behavioral rules, and technical learnings established during development.

## Tagged Guidelines and Learnings

- **[Planning & Process]**: When creating execution plans, avoid vague steps like "Add tests"; provide concrete actions specifying target files and functionality. Do not include cognitive tasks like "Analyze changes" as actionable steps; analysis must inform plan creation before execution.
- **[Planning & Process]**: When creating execution plans, inspect actual code structures (`read_file`, `grep`) before proposing modifications to remain grounded.
- **[Planning & Process]**: When creating an execution plan, the pre-commit step description must match the required wording: "Complete pre-commit steps to ensure proper testing, verification, review, and reflection are done."
- **[Code Quality & Standards]**: Do not blindly suppress `RuntimeWarning`s (e.g., division by zero or mean of empty slice) using `warnings.catch_warnings()`. Fix root causes natively using safe array masks (`np.where(mask, val, safe_val)`) or handling all-NaN slices explicitly.
- **[Code Quality & Standards]**: Generally preserve helpful code comments unless they are rendered outright incorrect by code modifications.
- **[Code Quality & Standards]**: Do not bundle dependency or lockfile changes (e.g., modifying `pyproject.toml` or regenerating `uv.lock`) into documentation-only updates to maintain strict separation of concerns.
- **[Dependencies & Environment]**: Install dev environments using `uv venv && source .venv/bin/activate && uv pip install -e ".[all,dev]"` (or `uv run`). Inline script metadata (PEP 723) defines file-specific dependencies in `src/eigenp_utils/` for isolated execution via `marimo` or `uvx` / `pipx`, while core dependencies reside in `pyproject.toml`.
- **[Dependencies & Environment]**: The project explicitly supports modern `numpy` (`numpy >= 2.0.0`). Bounding `numpy < 2` is strictly unacceptable. On Python 3.12, `pandas` must be constrained to `>=2.2.2` to prevent binary incompatibility (`ValueError: numpy.dtype size changed`). `typing-extensions` is pinned (e.g., `==4.12.2`) to prevent `anndata` import errors, `scanpy` is bounded to `>=1.11.0,<1.12.0`, `anndata` pinned to `0.11.1`, and `zarr` bounded to `<3`.
- **[Testing & CI]**: Test files in `tests/` must mirror source modules 1:1 (e.g., `tests/test_single_cell.py` corresponds to `src/eigenp_utils/single_cell.py`). Run the test suite using `uv run pytest tests/`.
- **[Testing & CI]**: When testing local `src/` changes, set `PYTHONPATH=src` (e.g., `PYTHONPATH=src uv run --with '.[all,dev]' pytest tests/`) to guarantee local source files are imported instead of stale cached versions in `site-packages`.
- **[Testing & CI]**: Every test function must include a clear docstring explaining its purpose, test strategy, and expected outcomes, avoiding trivial auto-generated summaries.
- **[Testing & CI]**: When testing plotting functions, prefer testing top-level API functions (e.g., `show_zyx_max_slice_interactive`) over directly testing internal low-level widget classes (`TNIASliceWidget`).
- **[Testing & CI]**: Tests generating Matplotlib plots must explicitly close figures via `plt.close(fig)` or `plt.close('all')` (e.g. in `finally` blocks or fixtures) to prevent memory leaks and figure warnings.
- **[Testing & CI]**: Leave internal 3rd-party warnings (from anndata, scanpy, seaborn) as they are; do not suppress `UserWarning`s unless fixing an underlying implementation bug.
- **[Testing & CI / AnyWidget]**: Frontends for `AnyWidget` testing requiring DOM interactions or `Proxy` behaviors must use headless browser testing with `pytest-playwright` and a local `http.server` to host the `_esm` module.
- **[Testing & CI / AnyWidget]**: CI uses `uv` with `pytest-playwright` and `playwright install chromium --with-deps`. Locally run `uv run --with '.[all,dev]' --with 'pytest-playwright' pytest`.
- **[Testing & CI / AnyWidget]**: When testing ground-truth click coordinates on `anywidget` annotators, dynamically locate main image axis `axXY` via `hasattr` or extent matching and route physical coordinates through `transData` and `transFigure.inverted()` to simulate raw browser click events with top-left origin.
- **[Plotting & AnyWidget]**: In `tnia_plotting_anywidgets.py`, legacy `sxy` and `sz` scaling parameters have been completely removed. All plotting functions and interactive widgets (`TNIASliceWidget`, `TNIAScatterWidget`, `IsoScatterWidget`, `show_zyx`, etc.) use `pixel_sizes` dictionary or tuple argument (`px`, `py`, `pz`).
- **[Plotting & AnyWidget]**: The `colors` parameter is deprecated in `tnia_plotting_anywidgets.py` plotting functions and interactive widgets; use `colormap` instead.
- **[Plotting & AnyWidget]**: In Matplotlib `violinplot` / `boxplot`, the `vert` parameter is deprecated; use `orientation='vertical'` or `orientation='horizontal'`.
- **[Plotting & AnyWidget]**: In `tnia_plotting_anywidgets.py`, ortho viewers (`show_zyx`, `TNIASliceWidget`, `TNIAAnnotatorWidget`, `TNIAScatterWidget`) position subplots via `fig.add_axes` based on physical image extents and a fixed `gap_in` parameter (default `1.0 / 16.0` inches), ensuring consistent gaps regardless of `figsize` or aspect ratio. Always calculate `figsize` or subplots layouts using physical spatial extents ($X \cdot p_x + Z \cdot p_z$) rather than raw voxel dimensions.
- **[Plotting & AnyWidget]**: To avoid positional indexing errors when dynamic subplots like `axLabels` are added, explicitly attach named axes (e.g., `fig.axXY`, `fig.axZY`, `fig.axXZ`) to the Matplotlib `Figure` object and reference them directly rather than relying on `fig.axes[i]`.
- **[Plotting & AnyWidget]**: In `tnia_plotting_anywidgets.py`, `channel_labels` axis (`axLabels`) in ortho viewers occupies height fraction `(0.05 + 0.003 * fontsize_pt)` of total row height, spans strictly the width of main XY axis, has transparent background (`axLabels.patch.set_visible(False)`), and renders a thin light gray `(0.85, 0.85, 0.85)` underbar at bottom with linewidth proportional to font size. Text `AnchoredOffsetbox` is anchored at `bbox_to_anchor=(0.5, 0.2)` (`loc='lower center'`). If `channel_labels` is omitted, it defaults to string names or hex codes of assigned colormaps, with rendered text and GUI channel elements darkened to 75% lightness via `get_gui_channel_color`.
- **[Plotting & AnyWidget]**: Interactive ortho view widgets replace separate position and thickness GUI sliders with a single range slider per dimension (`createRangeSlider`). In Python, `TNIAWidgetBase` uses `x_start`, `x_end`, `y_start`, `y_end`, `z_start`, `z_end` traits bidirectionally synchronized with center position (`x_s`, `y_s`, `z_s`) and half-thickness (`x_t`, `y_t`, `z_t`). Trait updates wrap notifications inside `with self.hold_trait_notifications():` to guarantee atomic multi-trait synchronization.
- **[Plotting & AnyWidget]**: `TNIAWidgetBase._render_wrapper` returns early while `_syncing_traits` is set. Because writing one slab trait makes the observers write its paired representation (`x_start` -> `x_s` + `x_t`) and `_render_wrapper` is observed on all twelve slab traits, without this guard a single slider step rasterized the figure three times and construction seven times. The trait that started the sync is itself observed by `_render_wrapper`, so the outer notification still renders exactly once; `_init_observers` renders explicitly after its initial sync. Any new observer that writes traits inside a sync must preserve this invariant.
- **[Plotting & AnyWidget]**: In `tnia_plotting_anywidgets.js`, `updateChannelsUI()` rebuilds the channel rows from scratch and the model exposes no `off`, so per-row callbacks are collected in `inputRefreshers` / `histogramRedraws` and the `model.on` subscriptions are registered once outside the rebuild. Never subscribe to the model from inside `updateChannelsUI()`.
- **[Plotting & AnyWidget]**: Interactive ortho viewer wrappers (`show_zyx_max_slice_interactive`, etc.) accept `channel_labels`. For `TNIAAnnotatorWidget`, `channel_names` property automatically appends an 'Annotations' channel.
- **[Plotting & AnyWidget]**: In `TNIAAnnotatorWidget`, click coordinates map to voxel indices by interpolating over physical limits (`xlim`/`ylim`), un-rotating coordinates if `rotate_view` is active, and calculating `np.floor(phys_coord / pixel_size)`. To prevent unbounded point deletion, clicks enforce maximum squared distance threshold (e.g. `dist > 400` for 20-pixel radius) in `_handle_click`.
- **[Plotting & AnyWidget]**: To map click coordinates on Matplotlib subplots with constrained aspect ratios (`imshow`), capture rendered image bounds by passing `ax.get_xlim()` and `ax.get_ylim()` through `ax.transData.transform` and `fig.transFigure.inverted().transform`, as `ax.get_position()` returns outer GridSpec cell bounds with empty margins.
- **[Plotting & AnyWidget]**: When transmitting Matplotlib bounding boxes to JS in `anywidget` implementations (`axis_bounds`), standardize coordinates to top-left origin directly in Python (`y0_js = 1.0 - y1_mpl`) and use a extraction helper in JS (`getBbox`).
- **[Plotting & AnyWidget]**: When plotting anisotropic crosshairs in `TNIASliceWidget` / `TNIAScatterWidget`, Y-axis coordinates scale by `self.sy` (not `self.sx`) and apply half-pixel offsets relative to pixel size factor: `(lim + 0.5) * self.sy`.
- **[Plotting & AnyWidget]**: In `resolve_color`, evaluate `is_colormap(c)` prior to `to_rgb(c)` to prevent standard Matplotlib colormaps sharing names with CSS colors ('pink', 'gray', 'hot') from resolving as single CSS hex colors. Use `matplotlib.colormaps[c]` catching `(ValueError, KeyError)`.
- **[Plotting & AnyWidget]**: In `src/eigenp_utils/labels_cmap_data.py`, `LABELS_CMAP_COLORS` is scaled in CIELAB space to ensure all 255 non-background label colors have lightness $L^* \ge 40$ against black backgrounds, maintaining index 0 as transparent `(0, 0, 0, 0)`.
- **[Plotting & AnyWidget]**: When compositing multiple image channels using Matplotlib colormaps, evaluate colormaps with `bytes=True` (`cmap(norm, bytes=True)[..., :3] / 255.0`) to correctly handle background values and prevent dark artifacts.
- **[Plotting & AnyWidget]**: In `src/eigenp_utils/plotting_utils.py`, `savefig_svg` and `set_plotting_style` support `editable_text` (default `True`) for exporting SVGs with editable text (`svg.fonttype = 'none'`, `axes.unicode_minus = False`). When post-editing Matplotlib SVGs in Inkscape, enable `xml:space="preserve"` for proper spacing. Avoid multi-line breaks or mixed LaTeX/text strings.
- **[Image Processing & Spatial Geometry]**: Image volumes and coordinate points follow (Z, Y, X) dimension ordering. Functions like `windowed_slice_projection` default to `axis=0`.
- **[Image Processing & Spatial Geometry]**: Functions taking `pixel_sizes` emit a `UserWarning` when `pixel_sizes` is `None`, falling back to isotropic (1.0) pixel sizes.
- **[Image Processing & Spatial Geometry]**: The `adjust_gamma_per_slice` and `adjust_brightness_per_slice` functions are deprecated; use `correct_z_intensity_decay` (with `method='gamma'` or `method='exponential'`) instead.
- **[Image Processing & Spatial Geometry]**: In `fit_basic_shading`, the darkfield is identifiable only from variation of per-sample baselines B_i (model I_i = B_i S + D). With a single image/volume (`s_s < 2`, e.g. one 3D volume with `is_3d=True`) `get_darkfield=True` warns once and fits the flatfield only (zero darkfield); the 'approximate' darkfield update is also skipped in iterations where no sample has B < 1. Previously this averaged empty sets: NaN residuals, "Mean of empty slice" every iteration, no ADMM convergence (60x256x256: 361 s, all-NaN output; now 2.8 s).
- **[Image Processing & Spatial Geometry]**: `@ensure_float_and_restore_dtype`: 8/16-bit integers are divided by the dtype max (signed types keep 0 at 0, range [-1, 1], like skimage `img_as_float`) and processed in float32; 32/64-bit integers are divided by the data's own max magnitude and processed in float64 (dtype-range scaling leaves ~1e-17 values); float32/float64 pass through. Restore with `_float_to_int` (round, clip strictly inside the range: `float(int64 max)` rounds up to 2**63 and would wrap).
- **[Image Processing & Spatial Geometry]**: In `correct_z_intensity_decay`, exponential decay models fit using Non-Linear Least Squares (`scipy.optimize.curve_fit`) bounded to ensure decay rate <= 0, seeded by exact Ordinary Least Squares (OLS) via `np.polyfit` on log-transformed data. When computing gamma correction factors from statistical intensity decay fits, avoid re-normalizing floating-point arrays by maximum value if already in `[0, 1]` range to prevent `log(1.0) = 0` division-by-zero errors. Gamma correction applies `s * (I/s)**g_i` with `g_i = log(t)/log(t*y_fit_i/y_ref)`, `t = min(y_ref, 0.5)` for [0,1] data (0.5 otherwise), `s = y_ref/t`: it maps each slice's fitted p99 onto y_ref, equals the classic `log(y_ref)/log(y_fit)` when y_ref <= 0.5, and avoids the collapse to gamma -> 0 as y_ref -> 1. Gain output is clipped to [0,1] only for [0,1] data, so raw-unit floats work.
- **[Image Processing & Spatial Geometry]**: `fit_basic_shading(fitting_mode='ladmap')` starts with a tiny `mu`, so the first iterations shrink S to 0 and the update is ~0. As in BaSiCPy, stop only when the residual ratio <= `optimization_tol` AND the update ratio <= `optimization_tol_diff`, and keep B when ||S||^2 == 0. `apply_basic_shading` with a timelapse `baseline` returns float32 by default (the result is zero-centred).
- **[Image Processing & Spatial Geometry]**: Morphological functions like `generate_morphological_surface_mask` pad cropped binary inputs by structuring element shape before calling `ndimage.binary_closing` to prevent object boundary truncation artifacts at bounding box edges.
- **[Image Processing & Spatial Geometry]**: `best_focus_image` performs extended depth of focus using subpixel cubic interpolation (`_cubic_interp_1d`), parabolic log-score peak refinement (`_get_fractional_peak`), and patch blending across 2D weight variants (`_get_1d_weight_variants`). Memory allocation churn is minimized by evaluating Catmull-Rom basis weights as scalars, caching unique 2D window matrices, pre-indexing focus sampling grids, and fast-pathing interior patch extraction.
- **[Image Processing & Spatial Geometry]**: 3D volume plane sampling and fitting utilities (`fit_plane_ransac`, `sample_volume_plane`, `generate_plane_basis`) in `src/eigenp_utils/image_and_labels_utils.py` adhere to the `pixel_sizes` dictionary convention.
- **[Single Cell Analysis]**: Use modern `anndata.concat()` over deprecated `.concatenate()`. In `kknn_ingest`, append `_kknn` suffix to transferred `.obs`, `.obsm`, and mapping confidence keys to prevent overwriting original query data.
- **[Single Cell Analysis]**: In `score_celltypes`, evaluate cell type signatures using `scanpy`, `binned`, or `binned_weighted` methods, plus 'net' versions (`net_scanpy`, `net_binned`, `net_binned_weighted`) subtracting negative marker scores. Net binned scores are strictly clipped to `[0, 1]`.
- **[Single Cell Analysis]**: For `scanpy` clustering via `sc.tl.leiden`, specify `flavor='igraph'`, `n_iterations=2`, and `directed=False`.
- **[Single Cell Analysis]**: `import_obs_to_adata_from_csv` handles missing observation keys by printing dataframe head and suggesting available columns in error message.
- **[Single Cell Analysis]**: `pflogpf` wraps Rust-based `scclr` package (PFlog / shifted-CLR normalization), verifies raw integer counts, lazily imports `scclr`, and prints installation instructions before raising `ImportError` if missing.
- **[Statistics & Applied Math]**: In NumPy/SciPy, match dtypes explicitly when performing in-place sparse array modifications (`W.data *= array`) to avoid `UFuncTypeError`.
- **[Statistics & Applied Math]**: In `stats.py`, `cohens_d` calculates exact Hedges' g correction factor using `scipy.special.gammaln`. `bootstrap_ci` uses BCa method with jackknife acceleration factor. `cohens_d` returns ±inf for constant groups with different means. The BCa jackknife leaves out rows (`axis=0`), matching the row-wise resampling. `remove_outliers` z-scores treat zero-variance columns as outlier-free (scipy's zscore gives NaN). `add_stat_annotations` reads the drawn group order from the axis tick labels when `order` is None (statannotations otherwise assumes first-appearance order).
- **[Statistics & Applied Math]**: `robust_standardize` implements hierarchical dispersion fallback (MAD -> MeanAD -> STD) with exact normal scaling factors (1.4826 for MAD, 1.2533 for MeanAD) to robustly standardize zero-inflated or heavily tied data without variance estimator collapse.
- **[Statistics & Applied Math]**: Multivariate outlier detection in `remove_outliers(method='mahalanobis')` calculates Mahalanobis distance via pseudo-inverse covariance matrix (`np.linalg.pinv`). In sample-estimated covariance, squared Mahalanobis distance $D^2$ is bounded by $(N-1)^2/N$; thresholding uses exact scaled Beta distribution bounds ($D^2 \sim \frac{(N-1)^2}{N} \text{Beta}(\frac{d}{2}, \frac{N-d-1}{2})$) to prevent extreme outliers from masking themselves in small datasets, falling back to Chi-Square if $N \le d+1$.

- **[Image Processing & Spatial Geometry]**: Drift estimation (`estimate_shift_1d_iterative`, `estimate_drift`) subtracts each max projection's minimum and uses plain cross-correlation (`phase_cross_correlation(..., normalization=None)`). A background offset times the window is a pedestal shared at zero shift; phase correlation (whitened spectrum) let it pull shifts to 0 and, once removed, let Poisson noise produce spurious peaks. Plain correlation + baseline removal cut cumulative errors 3-20x on camera-like videos. Noise-free smooth test profiles are sensitive to float32/float64 rounding under whitening: keep projections float32.
- **[Image Processing & Spatial Geometry]**: `image_and_labels_utils` resolves pixel sizes through `_pixel_sizes_to_spacing` (dict or sequence; `None` entries from uncalibrated readers -> 1.0 with a UserWarning naming the axis; non-finite / non-positive raise). `voronoi_otsu_labeling` keeps border seeds (`exclude_border=False`) and spaces seeds 3 finest-axis pixels apart in physical units (identical to `peak_local_max(min_distance=3)` for isotropic data). `sample_volume_plane` returns `{'Z': offset, 'Y': u, 'X': v}` and prefilters for `method='cubic'`. `extract_surface` sets refined height 0 for columns foreground from the first slice.

- **[Single-Cell / Reference mapping]**: `kknn_ingest` projects the query with `_project_onto_reference_pca`, which repeats the reference's preprocessing: `(x - var['mean']) / var['std']` when `sc.pp.scale` was used (centre BEFORE dividing), the same `±max_value` clipping (detected from values tied at the maximum), then centring on the column means of the matrix the PCA was fit on.
